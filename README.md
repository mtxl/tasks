# Таск-трекер — шаблон для командной работы

## Запуск

1. Открыть терминал в папке проекта
2. `python server.py`
3. Браузер: http://127.0.0.1:8000

## Что умеет

- Показывать список задач
- Добавлять задачу
- Удалять задачу

## Задание для команды

Выберите ОДНУ фичу и добавьте её в проект.

| № | Фича | Что делать | Сложность |
|---|------|-----------|-----------|
| 1 | Отметить выполненной | Кнопка «✓», поле `done`, зачёркнутый текст | ⭐ |
| 2 | Редактировать название | Форма редактирования, `POST /edit/{id}` | ⭐⭐ |
| 3 | Счётчик задач | «Всего: N, выполнено: M» на странице | ⭐ |
| 4 | Фильтр | Ссылки «Все / Активные / Выполненные» | ⭐⭐ |
| 5 | Дата создания | Поле `created` в JSON, вывод в списке | ⭐ |
| 6 | Приоритет | Поле `priority`, цветная метка | ⭐⭐ |
| 7 | Поиск | Поле ввода, фильтрация по подстроке | ⭐⭐ |
| 8 | Скачать CSV | Кнопка, файл через Content-Disposition | ⭐⭐ |
| 9 | Тёмная тема | Кнопка переключения CSS | ⭐ |
| 10 | Счётчик по дате | «Сегодня добавлено: N» | ⭐⭐ |
