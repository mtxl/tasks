# Проект «Таск-трекер»

## Что это

Учебное веб-приложение на Python: список задач хранится в `data.json`,
HTTP-сервер и вся логика — в `server.py`. Интерфейс и данные — на русском.

## Правила

- Только стандартная библиотека Python. Никаких `pip install`.
- Python 3.8: не использовать `match`, `list[str]`, `int | None`.
- Не менять формат `data.json` без отдельной задачи.
- Любые данные, которые попадают в HTML, экранировать через `html.escape`.
- Новые функции — с docstring на русском.
- После изменений запускать `python3 server.py` и проверять страницу в браузере.
- Не удалять и не перезаписывать `data.json` без подтверждения.
- Одна задача — одна фича. Не рефакторить соседний код «заодно».
- Для новой логики по возможности делать чистые функции, которые можно
  проверить тестами без запуска сервера.
- Тесты — `unittest`, без сторонних библиотек.

## Проверка

- Страница открывается на <http://127.0.0.1:8000>.
- `/add`, `/toggle/{id}` и `/delete/{id}` работают.
- После перезапуска сервера состояние сохраняется.
- `data.json` остаётся валидным JSON.
- Название задачи с `<script>` отображается как текст, а не выполняется.
- Код работает на Python 3.8.
